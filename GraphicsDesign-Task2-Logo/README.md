# Logo Design

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Graphics Design
**Assignment:** Task 2

## Objective & description

Create a reusable LUMEN Studio visual identity.

## Tech stack

Python, Pillow, SVG, PNG, PDF.

## Features implemented

- Full-color, monochrome, and reversed PNG/SVG variants
- Design rationale and prepared social-post copy
- Transparent logo backgrounds where applicable

## How to run / setup

Open the primary PNG/PDF/SVG in this folder. To regenerate the original graphics set, install Pillow with `python -m pip install Pillow` and run `python create_designs.py`.

Primary deliverable: [`logo\lumen_logo_full_color.png`](./logo\lumen_logo_full_color.png).

> The generator creates original artwork; the LinkedIn post copy is prepared locally and has not been published.
