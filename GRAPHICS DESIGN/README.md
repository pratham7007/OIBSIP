# Graphics Design

Original brand concept: **LUMEN Studio** (design with purpose). Assets use a consistent
teal, coral, warm-cream, and ink palette. All illustrations are original geometric artwork;
no stock photographs or third-party templates are used.

| Assignment | Deliverables |
|---|---|
| Posters & fliers | [Two A4 PNG posters](./posters/) |
| Logo | [Three transparent/reversed PNG variants, SVG vectors, rationale, and LinkedIn post copy](./logo/) |
| Business card | [Front/back preview PNGs and two-page print PDF](./business-card/) |
| Infographic | [Evidence-cited 800×2000 PNG at 150 DPI](./infographic/) |
| Magazine/brochure | [Six-page PDF and page previews](./brochure/) |

Run `python create_designs.py` from this folder to regenerate the exported assets. The
business-card PDF includes a 3 mm bleed on every side (91×61 mm page size), yielding an
85×55 mm trim size. The infographic uses a four-colour palette, five fact panels, and
multiple visual forms. The brochure uses six A4 pages, consistent headers/folios, original
full-bleed illustrations, 10–12 pt body copy, and a distinct pull quote. The LinkedIn copy
is prepared locally; no external post has been published.
