# Online Reservation System

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Java Development
**Assignment:** Task 1

## Objective & description

Train reservation and account application.

## Tech stack

Java, Maven, SQLite (for database-backed assignments).

## Features implemented

- Account registration and login
- Train selection, booking, PNR lookup, and owner-only cancellation
- SQLite persistence and parameterized SQL

## How to run / setup

Use JDK 25+ and Maven 3.8+. From this folder run `mvn clean package`, then `mvn exec:java`. Swing projects need a desktop session.

Primary deliverable: [`src/main/java/com/oasis/train/TrainReservationApp.java`](./src/main/java/com/oasis/train/TrainReservationApp.java).

> Database-backed demos create local data at runtime; do not use real credentials.
