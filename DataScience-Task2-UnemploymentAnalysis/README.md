# Unemployment Analysis

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Data Science
**Assignment:** Task 2

## Objective & description

Demonstrate regional/time-series analysis using clearly labelled deterministic synthetic data.

## Tech stack

Python, Jupyter, pandas, NumPy, scikit-learn, Matplotlib, Seaborn.

## Features implemented

- Regional and monthly trend views
- Pre/post period comparison and correlations
- Reproducible random seed; synthetic-data caveat

## How to run / setup

Install dependencies with `python -m pip install -r requirements.txt`, then run `jupyter lab .` and open the notebook. Run from this folder so its local `analysis_tasks.py` and `data` directory are available.

Primary deliverable: [`02_unemployment_analysis.ipynb`](./02_unemployment_analysis.ipynb).

> Synthetic-data provenance is called out in the notebook and must not be presented as measured findings.
