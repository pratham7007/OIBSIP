# Katherine Johnson Tribute Page

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Web Development & Designing
**Assignment:** Task 4

## Objective & description

Present a concise tribute to Katherine Johnson and her contributions to mathematics and spaceflight.

## Tech stack

HTML5, CSS3.

## Features implemented

- Biographical tribute content and milestones
- Readable typography, visual hierarchy, and responsive layout
- Related links and semantic page structure

## How to run / setup

Serve the folder with `python -m http.server 8000`, then open the stated local URL in a browser. Open `http://localhost:8000/tribute.html`.

Primary deliverable: [`tribute.html`](./tribute.html).
