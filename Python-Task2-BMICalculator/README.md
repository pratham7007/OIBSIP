# BMI Calculator

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Python Programming
**Assignment:** Task 2

## Objective & description

Calculate BMI and retain a local history for the user.

## Tech stack

Python 3.10+, tkinter, SQLite, and task-specific libraries.

## Features implemented

- BMI calculation and category presentation
- Desktop user interface and local history
- Handles invalid numeric input

## How to run / setup

Install dependencies using `python -m pip install -r requirements.txt`, then From this folder, run `python bmi_app.py`.

Primary deliverable: [`bmi_app.py`](./bmi_app.py).

> Live microphone, remote speech recognition, weather API, SMTP, and local chat runtime require the respective hardware/services and were not claimed as tested.
