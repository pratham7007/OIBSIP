# Personal Portfolio

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Web Development & Designing
**Assignment:** Task 2

## Objective & description

Showcase the student profile, skills, projects, and contact information in a personal portfolio.

## Tech stack

HTML5, CSS3.

## Features implemented

- Profile and biography sections
- Skills and project cards
- Contact section, portrait asset, and responsive navigation

## How to run / setup

Serve the folder with `python -m http.server 8000`, then open the stated local URL in a browser. Open `http://localhost:8000/`.

Primary deliverable: [`index.html`](./index.html).
