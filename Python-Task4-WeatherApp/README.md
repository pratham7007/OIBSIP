# Weather App

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Python Programming
**Assignment:** Task 4

## Objective & description

Retrieve and present weather for a requested location.

## Tech stack

Python 3.10+, tkinter, SQLite, and task-specific libraries.

## Features implemented

- Location-based weather lookup
- API-key configuration through environment variables
- Handles missing configuration and request errors

## How to run / setup

Install dependencies using `python -m pip install -r requirements.txt`, then Set the `OPENWEATHER_API_KEY` environment variable, then run `python weather_app.py` from this folder.

Primary deliverable: [`weather_app.py`](./weather_app.py).

> Live microphone, remote speech recognition, weather API, SMTP, and local chat runtime require the respective hardware/services and were not claimed as tested.
