# Unit Converter

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Android App Development
**Assignment:** Task 1

## Objective & description

Convert values across length, weight, and temperature categories.

## Tech stack

Java, Android SDK, Gradle.

## Features implemented

- Length, weight, and temperature categories
- Category changes reset unit choices
- Empty, malformed, and non-finite numeric input validation

## How to run / setup

Open this folder in Android Studio and run on an emulator/device, or run `.\gradlew.bat assembleDebug` in PowerShell.

Primary deliverable: [`app/src/main/java/com/oasis/internship/UnitConverterActivity.java`](./app/src/main/java/com/oasis/internship/UnitConverterActivity.java).

> Each task folder contains the full launcher app so its task can be run and explored independently; open the named screen from the launcher.
