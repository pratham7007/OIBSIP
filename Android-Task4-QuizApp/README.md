# Quiz App

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Android App Development
**Assignment:** Task 4

## Objective & description

Run a short interactive general-knowledge quiz.

## Tech stack

Java, Android SDK, Gradle.

## Features implemented

- Ten shuffled questions with immediate feedback
- Score and correct/incorrect totals
- Restart and saved in-progress state across recreation

## How to run / setup

Open this folder in Android Studio and run on an emulator/device, or run `.\gradlew.bat assembleDebug` in PowerShell.

Primary deliverable: [`app/src/main/java/com/oasis/internship/QuizActivity.java`](./app/src/main/java/com/oasis/internship/QuizActivity.java).

> Each task folder contains the full launcher app so its task can be run and explored independently; open the named screen from the launcher.
