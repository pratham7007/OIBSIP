# Password Generator

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Python Programming
**Assignment:** Task 3

## Objective & description

Generate configurable passwords with explicit boundary and character-type checks.

## Tech stack

Python 3.10+, tkinter, SQLite, and task-specific libraries.

## Features implemented

- Configurable length and character classes
- Optional ambiguous-character exclusion
- Input validation and cryptographically secure randomness

## How to run / setup

Install dependencies using `python -m pip install -r requirements.txt`, then From this folder, run `python password_generator.py`.

Primary deliverable: [`password_generator.py`](./password_generator.py).

> Live microphone, remote speech recognition, weather API, SMTP, and local chat runtime require the respective hardware/services and were not claimed as tested.
