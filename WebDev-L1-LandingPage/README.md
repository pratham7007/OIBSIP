**Internship:** Oasis Infobyte - OIBSIP

## Objective & description

## Tech stack

HTML5, CSS3.

- Responsive page structure and navigation
- Hero section, product benefits, testimonial content, and calls to action
- Consistent visual styling and mobile-friendly layout

## How to run / setup

Serve the folder with `python -m http.server 8000`, then open the stated local URL in a browser. Open `http://localhost:8000/`.

Primary deliverable: [`index.html`](./index.html).
