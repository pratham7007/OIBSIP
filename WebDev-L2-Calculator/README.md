# Browser Calculator

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Web Development & Designing
**Assignment:** Task 7

## Objective & description

Provide a simple interactive calculator through a browser-based interface.

## Tech stack

HTML5, CSS3, JavaScript.

## Features implemented

- Interactive calculator controls and display
- Client-side arithmetic and input handling
- Responsive presentation

## How to run / setup

Serve the folder with `python -m http.server 8000`, then open the stated local URL in a browser. Open `http://localhost:8000/calculator.html`.

Primary deliverable: [`calculator.html`](./calculator.html).
