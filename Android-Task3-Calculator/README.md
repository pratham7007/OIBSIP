# Calculator

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Android App Development
**Assignment:** Task 3

## Objective & description

Provide a keypad calculator with arithmetic precedence and error handling.

## Tech stack

Java, Android SDK, Gradle.

## Features implemented

- GridLayout keypad, decimal entry, clear, and backspace
- Arithmetic precedence
- Divide-by-zero error handling

## How to run / setup

Open this folder in Android Studio and run on an emulator/device, or run `.\gradlew.bat assembleDebug` in PowerShell.

Primary deliverable: [`app/src/main/java/com/oasis/internship/CalculatorActivity.java`](./app/src/main/java/com/oasis/internship/CalculatorActivity.java).

> Each task folder contains the full launcher app so its task can be run and explored independently; open the named screen from the launcher.
