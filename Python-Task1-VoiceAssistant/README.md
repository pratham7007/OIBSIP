# Voice Assistant

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Python Programming
**Assignment:** Task 1

## Objective & description

Provide a desktop assistant with text commands and opt-in voice controls.

## Tech stack

Python 3.10+, tkinter, SQLite, and task-specific libraries.

## Features implemented

- Command routing from a local JSON command catalog
- Optional speech input/output and local assistant responses
- Weather/email integrations remain opt-in and require configuration

## How to run / setup

Install dependencies using `python -m pip install -r requirements.txt`, then From this folder, run `python assistant.py`. Microphone/audio and remote speech recognition are optional integrations.

Primary deliverable: [`assistant.py`](./assistant.py).

> Live microphone, remote speech recognition, weather API, SMTP, and local chat runtime require the respective hardware/services and were not claimed as tested.
