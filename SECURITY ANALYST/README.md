# Security Analyst tasks

These are defensive learning materials and local-lab runbooks. No third-party system was
scanned, no network traffic was captured, no SQL injection was attempted, and no screenshots,
pcap files, or tool outputs have been fabricated. The workspace did not contain Nmap, Nikto,
Wireshark, or DVWA. Practical evidence items are clearly marked **not performed** and require
the student to run tools only in a lab they own or administer.
