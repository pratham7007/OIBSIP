# Digital Library Management System

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Java Development
**Assignment:** Task 5

## Objective & description

Local web-style library management application.

## Tech stack

Java, Maven, SQLite (for database-backed assignments).

## Features implemented

- Member/admin roles, catalogue, issues/returns, reservations, and fines
- Member list and library queries
- Local SQLite persistence and loopback-only server

## How to run / setup

Use JDK 25+ and Maven 3.8+. From this folder run `mvn clean package`, then `mvn exec:java`. Swing projects need a desktop session.

Primary deliverable: [`src/main/java/com/oasis/library/LibraryServer.java`](./src/main/java/com/oasis/library/LibraryServer.java).

> Database-backed demos create local data at runtime; do not use real credentials.
