# Advertising Sales Prediction

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Data Science
**Assignment:** Task 5

## Objective & description

Model sales against advertising spend using the ISLR Advertising dataset.

## Tech stack

Python, Jupyter, pandas, NumPy, scikit-learn, Matplotlib, Seaborn.

## Features implemented

- Dataset exploration and visualizations
- Regression analysis and model evaluation
- Reproducible notebook workflow

## How to run / setup

Install dependencies with `python -m pip install -r requirements.txt`, then run `jupyter lab .` and open the notebook. Run from this folder so its local `analysis_tasks.py` and `data` directory are available.

Primary deliverable: [`05_advertising_sales_prediction.ipynb`](./05_advertising_sales_prediction.ipynb).
