# Pizza Delivery Full-stack Application

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Web Development & Designing
**Assignment:** Task 8

## Objective & description

Provide a local full-stack pizza ordering experience with customer and administrator workflows.

## Tech stack

React, Vite, Node.js, Express, MongoDB.

## Features implemented

- Menu browsing, cart, ordering, and account flows
- Admin-only inventory and order status controls
- Email verification/reset support and optional Razorpay test-mode payment flow

## How to run / setup

Install Node.js and MongoDB. Copy `server/.env.example` to `server/.env`, set local MongoDB/JWT/admin values, install dependencies in the root, `server`, and `client`, then run `npm run dev`. Open `http://localhost:5173`.

Primary deliverable: [`client/index.html`](./client/index.html).

> Payment integration is restricted to test keys; without payment credentials the app uses a clearly labelled local demo confirmation.
