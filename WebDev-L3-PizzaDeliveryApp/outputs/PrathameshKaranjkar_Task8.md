# Pizza Delivery Full-stack Application - Submission Summary

- **Author:** Prathamesh Karanjkar
- **Assigned track:** Web Development & Designing
- **Assignment:** Task 8
- **Tech stack:** React, Vite, Node.js, Express, MongoDB

## Objective
Provide a local full-stack pizza ordering experience with customer and administrator workflows.

## Key features
- Menu browsing, cart, ordering, and account flows
- Admin-only inventory and order status controls
- Email verification/reset support and optional Razorpay test-mode payment flow

## Project entry point
- [`client/index.html`](../client/index.html)
- [Built client preview](./client-dist/index.html)

## Demo notes
The frontend production bundle is included as a build artifact. Backend ordering, authentication, and payment flows require the local server, database, and optional credentials described in the task README.
