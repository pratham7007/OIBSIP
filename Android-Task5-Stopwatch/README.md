# Stopwatch

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Android App Development
**Assignment:** Task 5

## Objective & description

Measure elapsed time with controls and laps.

## Tech stack

Java, Android SDK, Gradle.

## Features implemented

- Start, pause/resume, and reset controls
- Lap list
- Monotonic elapsed-realtime timing with background-aware updates

## How to run / setup

Open this folder in Android Studio and run on an emulator/device, or run `.\gradlew.bat assembleDebug` in PowerShell.

Primary deliverable: [`app/src/main/java/com/oasis/internship/StopwatchActivity.java`](./app/src/main/java/com/oasis/internship/StopwatchActivity.java).

> Each task folder contains the full launcher app so its task can be run and explored independently; open the named screen from the launcher.
