# Temperature Converter

**Internship:** Oasis Infobyte - OIBSIP
**Track:** Web Development & Designing
**Assignment:** Task 3

## Objective & description

Convert temperature values using an interactive browser interface.

## Tech stack

HTML5, CSS3, JavaScript.

## Features implemented

- Temperature conversion interface and dynamic result
- Input validation for empty or malformed values
- Responsive styling and accessible labels

## How to run / setup

Serve the folder with `python -m http.server 8000`, then open the stated local URL in a browser. Open `http://localhost:8000/`.

Primary deliverable: [`index.html`](./index.html).
